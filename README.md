# Sergi Izquierdo

Full-stack developer building production apps with Next.js, Supabase, and AI integrations. I ship real things — from municipal management platforms to RAG-powered note-taking systems.

Based in Tarragona, Spain. Open to remote work.

## What I'm building

**[Pista Rapita](https://pistarapita.cat)** — Municipal sports facility management platform. NestJS + React + PostgreSQL, serving real users and bookings for a local government.

**[ShenaniForge](https://shenaniforge.com)** — Community platform with 26 Supabase tables, full RLS multi-tenant isolation, codec pipelines, and data visualizations.

**SynapseNotes** — AI-powered note-taking with RAG search, pgvector embeddings, and streaming chat. Built with Next.js 16 + Supabase + Vercel AI SDK. My thesis project at URV.

**DEIM Manager** — Enterprise department management system at URV. Spring Boot + Java 21, 115 Flyway migrations, CAS SSO, Hibernate Envers audit trails.
